# 3-minute demo script

Record on an iPhone 15 simulator (⌘R in Xcode) with QuickTime → New Screen Recording. Keep the Xcode console hidden. Speak to a non-technical viewer.

| Time | Screen | Say |
|---|---|---|
| 0:00–0:20 | Empty screen with "Try asking" suggestions | "SupportSense answers support questions from a help library stored on the phone. No internet, no AI bill, and nothing you type leaves the device." |
| 0:20–0:50 | Tap **I forgot my password** | "The best article comes first. The green badge says High confidence. That only appears when the article covers most of what you asked and clearly beats the runner-up. The summary is a sentence quoted from the article, so it can't make things up. And the search took well under a millisecond." |
| 0:50–1:15 | Type **charge on my card** | "Two plausible answers: an unrecognised charge, and refunds. The first is High, the second Medium. The app separates 'this is it' from 'this might help'." |
| 1:15–1:40 | Type **speak to someone real** → no results; then **binned a folder by mistake** → Low banner | "Here's where it struggles. People say 'binned' and the articles say 'deleted'. Instead of pretending, it says it's not sure and suggests rephrasing or contacting support." |
| 1:40–2:10 | Thumbs-up a card, thumbs-down another, open **Feedback log**, tap Export | "Every vote is saved on the device and can be exported for the support team. Votes gently boost helpful articles in future searches, capped at 15% so a few clicks can't bury the right answer." |
| 2:10–2:45 | Switch to the README eval table on GitHub | "On questions I wrote, it gets 98% right. On a blind set written like real users, 23%. I report both. The number that held up is the one that matters for trust: it never labelled a wrong answer High." |
| 2:45–3:00 | DESIGN.md roadmap | "Next: on-device semantic matching so 'binned' finds 'deleted'. The target is 60% on the blind set with zero confidently wrong answers." |
